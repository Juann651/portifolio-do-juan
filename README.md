# Portfólio — Juan Santos Leal

Portfólio pessoal desenvolvido para apresentar meus projetos, habilidades técnicas, experiências e evolução na área de tecnologia.

Feito com **HTML, CSS e JavaScript puro**, em uma única página, sem framework e sem etapa de build.

## O que tem no site

- **Sobre mim:** apresentação pessoal e objetivos
- **Habilidades:** web e design, programação, bancos de dados, ferramentas, IA e automação, escritório (básico) e habilidades pessoais
- **Projetos:** lista dos repositórios públicos do meu GitHub, atualizada automaticamente, com link para ver todos
- **Experiência:** trajetória profissional
- **Formação e cursos:** Bacharelado em Sistemas de Informação e cursos complementares
- **Idiomas**
- **Contato:** email, telefone, GitHub e LinkedIn

## Tecnologias

- HTML5, CSS3 e JavaScript
- API pública do GitHub, para listar os repositórios
- Fonte Plus Jakarta Sans (Google Fonts)

## Estrutura

```
portifolio-do-juan/
├── index.html      # página completa
├── foto.jpg        # foto de perfil
├── curriculo.pdf   # currículo para download
└── README.md
```

## Como rodar

Não precisa instalar nada. Abra a pasta no VS Code e rode o `index.html` com a extensão **Live Server**, ou abra o arquivo direto no navegador.
